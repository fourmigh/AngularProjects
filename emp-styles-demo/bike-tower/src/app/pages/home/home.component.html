workflow

三步完成换肤

01

编辑键值

在左侧选择组件或页面分组，在右侧调整背景、边框、圆角、颜色、阴影等。

02

实时预览

中间 iframe 实时显示 bike-tower 的组件展示页，也可以切换到 emp 自身的页面。

03

导出接入

导出 Less 到项目的 src/styles/skins，并在 styles.less 中引入， 重启 dev server 即可生效。

tokens

皮肤键值

按组件分组

同一类组件只维护一组键值，例如所有卡片共用 --emp-card-*。

--emp-card-bg: #ffffff;
--emp-card-border-color: #dbdbdb;
--emp-card-radius: 12px;
--emp-card-shadow: ...;

全局与自定义

全局色板、字体和圆角放在全局分组；自定义组件的键值纳入 custom 分组。 

--emp-color-primary: #00679e;
--emp-font-size-base: 15px;
--emp-bt-stat-bg: #ffffff;
export

两种导出格式

Class 属性

每个组件一个 class，里面是普通 CSS 属性，可读性最好。

.emp-card {
  background: #ffffff !important;
  border: 1px solid #dbdbdb !important;
  border-radius: 12px !important;
}

分组变量

按组件分块的 CSS 变量，自定义组件可以直接读取。

:root {
  --emp-card-bg: #ffffff;
  --emp-card-border-color: #dbdbdb;
  --emp-card-radius: 12px;
}
custom components

自定义组件如何接入皮肤

bike-tower 自定义组件使用 --emp-bt-<component>--<property>，emp-ui 自定义组件使用 --emp-custom-<component>--<property>。新增组件后运行 npm run skins:manifest，编辑器会自动生成分组，不需要手改 skin-schema 或 skin-classes。

01

组件样式使用变量

按命名约定使用 var()，并保留默认 fallback。

.bt-timeline {
  background: var(--emp-bt-timeline--background, #ffffff);
  border: 1px solid var(--emp-bt-timeline--border-color, #dbdbdb);
  border-radius: var(--emp-bt-timeline--radius, 12px);
}
02

运行自动扫描

脚本扫描 components 目录，按属性字典生成字段和 Class 规则。

cd emp
npm run skins:manifest

# 生成
# custom-skin.generated.ts
03

展示并重新导出

在 showcase 页面使用新组件，然后重新导出 current.less。

<bt-timeline title="项目里程碑">
  ...
</bt-timeline>

已有皮肤需要重新导出一次，才会包含新的组件规则。

scope

页面启用与跳过

默认

使用皮肤

页面什么都不用加，默认应用 current.less 中的皮肤。

跳过

路由 skin: false

在路由 data 中标记 skin: false，skinGuard 在激活前设置 body。

{
  path: 'compare/plain',
  data: { skin: false },
}
局部

.emp-skin

需要局部换肤时，把皮肤限定在 .emp-skin 容器内。

<div class="emp-skin">
  <app-showcase />
</div>
