workflow

三步完成换肤

01

编辑键值

在左侧选择组件或页面分组，在右侧调整背景、边框、圆角、颜色、阴影等。

02

实时预览

中间 iframe 实时显示 bike-tower 的组件展示页，也可以切换到 emp 自身的页面。

03

导出接入

导出 Less 到项目的 src/styles/skins，并在 styles.less 中引入， 重启 dev server 即可生效。

tokens

皮肤键值

按组件分组

同一类组件只维护一组键值，例如所有卡片共用 --emp-card-*。

--emp-card-bg: #ffffff;
--emp-card-border-color: #dbdbdb;
--emp-card-radius: 12px;
--emp-card-shadow: ...;

全局与自定义

全局色板、字体和圆角放在全局分组；自定义组件的键值纳入 custom 分组。 

--emp-color-primary: #00679e;
--emp-font-size-base: 15px;
--emp-bt-stat-bg: #ffffff;
export

两种导出格式

Class 属性

每个组件一个 class，里面是普通 CSS 属性，可读性最好。

.emp-card {
  background: #ffffff !important;
  border: 1px solid #dbdbdb !important;
  border-radius: 12px !important;
}

分组变量

按组件分块的 CSS 变量，自定义组件可以直接读取。

:root {
  --emp-card-bg: #ffffff;
  --emp-card-border-color: #dbdbdb;
  --emp-card-radius: 12px;
}
custom components

自定义组件如何接入皮肤

bike-tower 自定义组件使用 --emp-bt-<component>--<property>，emp-ui 自定义组件使用 --emp-custom-<component>--<property>。默认 showcase 不展示自定义组件； 新增组件后运行 npm run skins:manifest，编辑器会自动生成分组， showcase 会通过生成的注册表自动挂载，不需要手改 skin-schema、 skin-classes 或 showcase 模板。

01

组件样式使用变量

按命名约定使用 var()，并保留默认 fallback。

.bt-timeline {
  background: var(--emp-bt-timeline--background, #ffffff);
  border: 1px solid var(--emp-bt-timeline--border-color, #dbdbdb);
  border-radius: var(--emp-bt-timeline--radius, 12px);
}
02

运行自动扫描

脚本扫描 components 目录，生成皮肤分组和 showcase 注册表。

cd emp
npm run skins:manifest

# 或在仓库根目录
./build.sh manifest

# 生成
# custom-skin.generated.ts
# custom-showcase.generated.ts

皮肤分组和 showcase 注册表生成文件都不提交，安装依赖和启动/构建前会自动生成。

03

配置默认数据并重新导出

在组件同目录新增 <component>.defaults.json，填写 inputs； 多个示例用 variants。 

{
  "inputs": {
    "title": "最近活动",
    "items": []
  }
}

每个组件一个 defaults JSON，生成器会自动合并。 已有皮肤需要重新导出一次，才会包含新的组件规则。

手动与自动

步骤 类型 说明
创建组件 .ts / .less 手动 放到 components/ 目录
写变量与 fallback 手动 --emp-bt-<component>--<property>
自动加入 showcase 自动 生成注册表，showcase 用 NgComponentOutlet 渲染
提供默认演示数据 手动可选 组件同目录 <component>.defaults.json
排除自动展示 手动可选 在 defaults 中设置 auto: false； ng-content 默认跳过
新属性名补字典 手动 仅新属性需要，写入 skin-properties.json
特殊 label / selector / 复杂规则 手动可选 写入 custom-skin-overrides.json
运行 npm run skins:manifest 半自动 两端 start / build 前，以及 emp postinstall 自动执行
扫描并生成清单 自动 key / fallback / fields / classRules / previewTarget / defaults 数据 / showcase 注册表
合并进编辑器 schema 自动 skin-schema.ts 导入生成结果
调整颜色和尺寸 手动 编辑器里操作
导出 current.less 手动 点击导出
重启 dev server 手动 Less 是构建期编译

默认 showcase 只有基础组件。custom-showcase.generated.ts 不提交， 由 postinstall、start、build 生成。dev server 已启动时新增组件， 需要重新运行 npm run skins:manifest，或直接重启服务。

新增属性：两种路径

已有属性名

只改组件 LESS

属性名已经在 skin-properties.json 中，例如 border-color。

.bt-activity-timeline {
  border: 1px solid
    var(--emp-bt-activity-timeline--border-color, #dbdbdb);
}
新属性

组件 LESS + 属性字典

新属性名需要补 skin-properties.json，否则只能使用通用 label/type。 

{
  "battery-fill": {
    "label": "电量填充",
    "type": "color"
  }
}

生成器自动完成

扫描变量、解析 fallback、生成字段、classRules 和 previewTarget，并合并进 skin-schema；同时生成 showcase 注册表，由 NgComponentOutlet 自动渲染。Class 导出自动生成 global / scoped / preview / combined 段。
